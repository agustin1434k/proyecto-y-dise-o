# GestionAlumnos
1. Iniciar MySQL en XAMPP.
2. NetBeans: Archivo > Abrir proyecto > carpeta GestionAlumnos.
3. Clic derecho en el proyecto > Build with Dependencies (descarga el driver; se necesita internet).
4. Ejecutar PruebaConexion (clic derecho > Run File) y sacar captura: "Conexión exitosa".
5. Ejecutar PruebaAlumnos y sacar captura del listado.
Ajustar en PruebaAlumnos los valores `curso` y `apellido` a datos que existan en tu tabla.
Si tu tabla tiene otras columnas, cambiar los nombres en PruebaAlumnos.mostrar().
